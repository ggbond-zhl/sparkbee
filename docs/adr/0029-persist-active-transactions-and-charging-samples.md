# 持久化活动交易与充电采样

SparkBee 将活动交易运行态及其充电采样写穿持久化到 PostgreSQL：开始交易确认后必须在 API 返回前持久化，充电采样必须在对应 MeterValues 发送及 SSE 发布前持久化，结束交易必须在释放活动交易前持久化。服务启动后异步恢复存在活动交易的桩实例，单桩恢复失败不阻止服务启动；运行调试台通过独立接口加载各枪口当前活动交易最近 7 天的采样并由 SSE 追加，交易结束后立即隐藏曲线，不拼接或回退到历史交易。

已结束交易保留 7 天，活动交易本身不因时间过期，但其采样使用滚动 7 天窗口；删除桩实例时同步删除交易与采样。这个决策用数据库一致性和额外恢复复杂度换取页面重入、浏览器刷新、服务休眠、重启及重新发布后的连续调试体验，并取代 ADR-0010 的纯进程内运行边界；ADR-0019 的运行状态快照继续只承载当前状态，不承载曲线时间序列。
