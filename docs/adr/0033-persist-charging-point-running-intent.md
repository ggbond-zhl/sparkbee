# 持久化桩实例运行意图并在服务重启后恢复

SparkBee 为每个桩实例持久化 running 或 stopped 运行意图，并在服务器开始监听后并行、独立地恢复所有 running 桩实例，使人工启动的空闲桩也能跨重启保持长期连接。运行意图是用户期望，必须与当前进程中的实际运行状态分别展示；启停操作先持久化意图再操作 Actor，实际启动失败不清除 running，实际停止失败不清除 stopped，服务退出本身也不改变意图。

运行意图优先于活动交易恢复：stopped 桩实例即使存在活动交易也不自动启动，交易保留至用户再次启动。恢复失败不阻塞服务器或其他桩实例，也不增加现有 WebSocket 重连和 Boot Pending 之外的无限重试；用户可以手动重试或明确停止。首次迁移时，有活动交易的既有桩实例设为 running，其他既有桩实例与新建桩实例默认 stopped；本决策据此调整 ADR-0029 中无条件恢复活动交易桩实例的规则。
