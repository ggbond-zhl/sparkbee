# Triage Labels

工程技能使用五个标准 triage 角色。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，AFK agent 可以直接接手 |
| `ready-for-human` | `ready-for-human` | 需要真人实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色时，使用本表右侧对应的标签字符串。

如本仓库后续采用不同词汇，直接修改右侧列即可。
